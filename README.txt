Folio 1.0.14 — portable notes app for Windows
Created by iK4w4 — Support: https://t.me/AskKawaBot

HOW TO USE
Just run Folio.exe. No install. It creates its files next to the exe:

  Notes/          your notes, plain .md files (folders are subfolders)
  settings.json   theme, palette, zoom, font
  pins.json       pinned notes
  folders.json    folder list
  trash.json      trash records
  Trash/          deleted notes (restorable inside the app)
  All Notes.txt   one-file backup of everything, updated on every change

Copy the whole folder to a USB drive or another PC and everything moves
with it. Your notes stay readable as plain Markdown even without the app.

100% offline: no accounts, no cloud, no tracking, no network calls.
